# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues or pull requests.

If GitHub private vulnerability reporting is enabled for this repository, use the repository's Security → Advisories → Report a vulnerability flow. If it is not enabled, contact the repository maintainer privately through GitHub before sharing technical details.

Include:
- affected release or commit;
- affected component and deployment context;
- concise reproduction steps and impact;
- relevant logs with credentials, tokens, personal data, and vault material removed.

Do not include passwords, recovery keys, private keys, access tokens, or unredacted user data in a report.

## Scope and support

Security fixes are developed against the current main branch. A formal release support window has not yet been published; please identify the exact version or commit affected when reporting an issue.
