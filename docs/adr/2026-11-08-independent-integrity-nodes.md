# Legacy Dual-Integrity-Node ADR — Superseded

This ADR documented two independently hosted integrity monitors. The owner has since selected one independent security node on HelioHost, with the owner's phone as the device-authorisation root.

The dual-node requirement is not part of the current target architecture. Do not provision a second integrity monitor or interpret the former Node A/B model as active.

Original ADR archived at [2026-11-08-independent-integrity-nodes-archive.md](2026-11-08-independent-integrity-nodes-archive.md).
